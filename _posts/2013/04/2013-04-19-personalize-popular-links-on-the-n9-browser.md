[![N9 default browser](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-30-07-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-30-07.png>)Even if the Nokia N9 has a bunch of quite good alternative browsers, like Opera or Firefox among the others, you might choose to use the default browser instead - it's quite smooth and has a good HTML5 compatibility; furthermore, you can set a link as homescreen shortcut. However, the lack of the bookmarking feature is quite annoying - luckily MeeGo is highly customizable, so an app can help you. It's called MyTopSites and you can download it [from the Nokia Store](<http://store.ovi.com/content/225055>). [![MyTopSites on Nokia Store](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-30-25-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-30-25.png>) Now you will be able to customize the _Most popular sites_ page on your browser. Let's see how; once you open the app, you will be prompted on a screen like this: [![MyTopSites](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-32-35-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-32-35.png>) You can easily customize or delete existing links or create a new one, aside from pick a color for the font or the background. [![MyTopSites - create a new link](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-08-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-08.png>)[![MyTopSites - pick a font color](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-25-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-25.png>)[![MyTopSites - pick a background color](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-38-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-38.png>) Right under those options, you can see _Access Count - Position_ ; there you can set the link position on the list. Set 5 or higher value - an higher value corresponds to an higher position on the list. Remember to close all your browser windows and to save your changes before you close. [![MyTopSites - save a link](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-17-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_00-33-17.png>) This is the final result: [![MyTopSites - customized links](/assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_01-02-18-1.png)](</assets/posts/2013/04/personalize-popular-links-on-the-n9-browser-2013-04-19_01-02-18.png>) Note: if you clear your browsing history, custom links will be resetted.
